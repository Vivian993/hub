# 我的公車小幫手 V1

這是一個給小朋友使用的簡單 PWA 公車查詢 App 原型。

## 已完成
- 🏫 我要去學校
- 🏠 我要回家
- 📍 附近站牌
- ❤️ 收藏常用站牌
- ⭐ 常用路線
- 📅 今天班次
- 🔔 提醒設定介面
- 📍 手機定位
- 🚌 上車站／方向／下車站確認
- 📱 PWA，可加入手機主畫面

## 重要說明
目前 `app.js` 使用「示範站牌／示範班次」，方便先測試操作流程。
正式版應將資料層改接桃園市政府公車資料服務，並依資料服務的申請／授權規範使用。

### 正式版資料層建議
建立 `tycg-api.js`：
1. 取得站牌清單
2. 取得路線與站序
3. 依 GPS 計算附近站牌
4. 取得指定站牌的預定班次
5. 取得公車即時動態
6. 將 API 回傳格式轉成 App 內部統一格式

## 如何測試
最簡單：
- 將整個資料夾上傳 GitHub
- 開啟 GitHub Pages
- 用手機開啟網址
- 可加入手機主畫面

也可以使用任何靜態網站主機。
